## Architecture decisions

Retain the three destinations and all six routes. Prefer pure decision
functions and scoped controllers over inline view decisions. A wholesale
rewrite would replace stable governance and make regressions harder to locate;
another layer of UI overrides would leave competing state owners intact.
Templates receive facts and actions; services retain permissions, persistence
and actual verification. No autonomous coding or deployment features are added.

Host synchronization will separate attempted delivery from applied state:
generation, revision, base revision, message identity and workspace/session
scope accompany snapshots/patches, and only an applied ACK advances the host
baseline. One in-flight update and a coalesced latest update bound the queue.
Duplicate/late updates are fenced, retries are bounded, and failed patch
recovery uses a full snapshot. Cancellation remains outcome unknown.

Learning uses one deterministic resolver for readiness, plan/step state,
evidence gates, training, reviews and recovery. One descriptor supplies title,
label, target, disabled state and intent. Optional evidence review cannot
override an available learning step.

Image attachment staging validates count and byte budgets before full reads,
checks actual file signatures and decoded dimensions, and preserves draft
scope across asynchronous completion. The server validates the same transport
constraints. Vision capability requires a content-dependent visual answer,
separate from protocol acceptance, tool use and streaming.

## Execution ownership

Engineering owns workflows/package/version metadata and narrow Python type and
attestation endpoint fixes. Product owns App and Learning resolver/rendering.
Runtime owns host bridge, store, sync protocol and surface render lifecycle.
Root owns multimodal service/provider truth, evidence/journey audit, probes,
integration and actual native/SSH acceptance. Shared contracts are agreed before
implementation; only root commits or pushes after corresponding checks pass.
