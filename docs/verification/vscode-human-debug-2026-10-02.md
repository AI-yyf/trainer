## 主要修复

- Provider 表单层级、键盘导航、隐藏控件焦点、保存与测试忙碌状态、nullable ACK、凭据模式导致的假未保存状态。
- 沙盒权限证据在扩展类型和映射中丢失；项目 root scope 初始化、旧数据恢复、独立训练选择持久化。
- 无正式计划时真实历史和上传资料被误清；搜索回包覆盖清空动作；预览缓存边界。
- 流式取消等待未完成迭代导致锁死、晚到数据覆盖取消；末帧 nullable 字段导致结束消息被拒绝。
- 明确生成计划操作被自动改成解释模式；普通继续学习回复覆盖正式计划当前步骤。
- 代码块清理破坏 Python 缩进；回复保存 UTF-8、请求确认与超时；训练回带实际答案、完整代码及验证状态。
- 原生技能草稿生成缺失；已保存技能在恢复时被三层过滤隐藏。
- 普通文件评估误用正式任务要求并覆盖正式计划；现在计划推进必须匹配明确任务 ID，实战卡验证只绑定精确目标路径和当前卡片，缺失动态测试不能伪造通过。
- 紧凑训练卡恢复“下一张”和先看资料；修复点击事件误作训练主题导致请求无法序列化。学习页恢复“更多”中的证据与变更入口，单阶段计划去除重复展示。下一张完整原生闭环仍在复测。
