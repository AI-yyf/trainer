# Trainer 1.5.0-rc 15 分钟本机安装试用与 T-0028 签收清单

本清单面向真实安装态 VSIX 验证与人工教学质量签收（`T-0028`）。仓库内不保存任何真实 API 密钥；配置连接时请使用你自己的服务商地址与密钥。

## 1. 前置检查与安装（约 3 分钟）

1. 检查打包产物与安装态校验脚本已通过：
   - 打包 VSIX：`extension/trainer-extension-1.4.4-darwin-arm64.vsix`
   - 安装态冒烟：`TRAINER_SKIP_VSIX_REBUILD=1 node extension/scripts/verify-vsix-install.mjs`
2. 在本机 VS Code 安装 VSIX（建议先备份或使用独立 `--user-data-dir` / `--extensions-dir`）：
   ```bash
   code --install-extension extension/trainer-extension-1.4.4-darwin-arm64.vsix --force
   ```
3. 打开一个本地练习或代码项目目录，在左侧栏打开 Trainer 视图。

## 2. 配置模型连接与统一资料库根目录（约 3 分钟）

1. 点击右上角齿轮打开 **设置**，进入模型连接配置：
   - 服务地址：`https://api.example.com/v1`（替换为你的 OpenAI 兼容端点）
   - 模型：推荐使用支持工具调用与流式输出的模型（如 `MiniMax-M3.1-Flash` 或 `MiniMax-M2.7`）
   - API Key：`sk-...`（通过安全存储保存，不会落盘至仓库）
2. 点击测试连接，确认状态为可用。
3. 在工作区设置中确认已绑定学习文件夹 `<LibraryRoot>`，并将目标代码仓加入或浏览打开。

## 3. 核心路径实测（约 6 分钟）

1. **资料库默认 Markdown + 图片与搜索框**：
   - 切到顶部的 **资料** 页签。
   - 确认顶部工具栏直接包含 **搜索资料** 输入框，输入关键词可实时过滤条目；取消勾选/不启用原始二进制下载时，导入网页或 PDF 后资料库与沙盒只保留 `.md` 文档与配套提取图片（`assets/<id>/*.png`），不展示多余的上下文恢复提示条。
2. **多轮引导与零污染代码仓**：
   - 切回 **对话**，围绕当前代码文件的具体问题发起至少 2 轮提问（例如："为什么这段重试逻辑的幂等键不能只放在单进程内存 dict 里？"）。
   - 观察流式回复是否正常收尾（SSE 流正常关闭，无无限转圈）、回复内容是否贴合当前工作区文件且不含内部工程术语。
   - 检查代码仓 `git status`：确认零 `.trainer/`、`Trainer Library/` 或临时文件写入用户代码仓库，所有运行时与资料均在 `<LibraryRoot>` 下。
3. **断网恢复重试（Journey F）**：
   - 临时断开模型服务/使用无效代理触发一次失败提示后，恢复网络并直接重发同一消息（不重新打开设置页）。
   - 确认重发不会滞留旧的 `Provider test failed` 错误，能够直接恢复成功应答。
4. **学习抽屉（当前目标 / 到期练习 / 掌握进度）**：
   - 点击右上角书本图标打开 **学习** 抽屉。
   - 确认界面表述正式清晰（`当前目标`、`到期练习`、`掌握进度`、`第 X / Y 阶段`、`后续阶段`、`已验证 N 次`、`未验证 / 需辅助 / 独立完成 / 稳定掌握 / 待巩固`），且 **掌握进度** 卡片只显示**一条统一的分段能力条**、不出现虚假百分比。
