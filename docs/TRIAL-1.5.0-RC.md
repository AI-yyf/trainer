# Trainer 1.5.0-rc 15 分钟本机安装试用与 T-0028 签收清单

本清单面向真实安装态 VSIX 验证与人工教学质量签收（`T-0028`）。仓库内不保存任何真实 API 密钥或私有中转地址；配置连接时请使用你自己的服务商地址与密钥。

## 1. 前置检查与安装（约 2 分钟）

1. 确认最新干净源码态打包产物与安装态校验已通过：
   - 打包 VSIX：`extension/trainer-extension-1.4.4-darwin-arm64.vsix`（构建凭据：`extension/trainer-extension-1.4.4-darwin-arm64.vsix.build.json`，`sourceDirty: false`）
   - 安装态冒烟：`TRAINER_SKIP_VSIX_REBUILD=1 node extension/scripts/verify-vsix-install.mjs`
2. 在本机 VS Code 安装 VSIX（建议先备份或使用独立 `--user-data-dir` / `--extensions-dir`）：
   ```bash
   code --install-extension extension/trainer-extension-1.4.4-darwin-arm64.vsix --force
   ```
3. 打开任意本地代码项目目录，在左侧栏打开 Trainer 视图。

## 2. 冷启动、模型连接与代理直连（约 3 分钟）

1. **冷启动零拦截**：打开未绑定过的代码项目时，确认无需先穿过 4 选项准入墙即可直接在底部唯一输入框开始对话；首次需要落盘资料、笔记或长期计划时再一键绑定 `<LibraryRoot>`，且代码仓始终零写入。
2. 点击右上角齿轮打开 **设置 → 连接**：
   - 服务地址：填写你的 OpenAI 兼容服务根地址（例如 `https://api.example.com/v1`）
   - 模型：选择支持流式与工具调用的模型（如 `MiniMax-M2.7` 或 `MiniMax-M3.1-Flash`）
   - API Key：`sk-...`（仅存入操作系统钥匙串，绝不写入仓库或 `<LibraryRoot>`）
   - **网络代理**：若本机开启了代理环境变量导致 502 或超时，在连接表单中将 **网络代理** 切换为 **忽略系统代理（直连）**，点击 **测试连接** 确认可用。

## 3. 核心闭环实测（约 7 分钟）

1. **唯一输入框主权与可折叠练习卡**：
   - 在 **对话** 页确认全屏有且仅有一个底部输入框（无第二作答输入框、无卡片库 CRUD 管理表单）。
   - 存在当前练习时，点击 **收起练习 / 展开练习** 可顺滑折叠释放对话阅读空间；作答、要提示、提交反思均从底部唯一输入框完成。
2. **RethinkFun 状态流深度讲透 + 落盘资料库 `.md`**：
   - 在底部输入框发送一条深度原理请求（例如：“请用状态流方式彻底讲明白 Scaled Dot-Product Attention 为什么必须除以 sqrt(d_k)，给出推导和最小 Python 代码，并帮我把这份讲稿保存成资料库里的 Markdown 笔记”）。
   - 确认讲解从旧方案卡住与变量角色切入、逐步消缺口推导（无“显然/大家都知道/代入即得”等垫词）、代码逐项回指理论并做认知回收；且讲稿自动保存至 `<LibraryRoot>/Trainer Library/`，用户代码仓 `git status` 零污染。
3. **资料页检索分离与 Markdown 图文预览**：
   - 切到顶部 **资料** 页签：确认顶部为本地快速过滤框（`筛选资料`），底部唯一输入框为 `围绕资料提问或生成讲稿`，职责清晰不打架。
   - 点击刚才保存的 `.md` 讲稿（或导入的 PDF/网页规范化文档）：确认默认以 **VS Code Markdown 渲染预览** 打开（配套图片 `assets/<id>/*.png` 开箱可见），菜单中保留 **打开源文件** 次要选项，行内可一键 **围绕此资料提问**。
4. **真实代码引导 + 唯一输入框查询学习真相**：
   - 切回 **对话**，让教练查看当前项目的某个代码文件并指出并发/边界缺口，确认教练只引导与给出验证标准，**绝不直接改写你的项目代码**。
   - 直接在底部唯一输入框发问：“帮我核查我目前的完整学习计划阶段和掌握进度的具体验证证据，再出 1 道闭卷推理型复习题”，确认教练如实基于服务端数据作答（0 证据时绝不编造掌握度）。
   - 点击右上角书本图标打开 **学习** 抽屉：确认只读三卡（`当前目标`、`到期练习`、`掌握进度` 单一 4 段正式能力条、无百分比/无内部系统词），底部轻提示引导从输入框查看细节。
5. **断网恢复重试（Journey F）**：
   - 临时断开模型服务或切无效代理触发一次失败后恢复网络并直接重发同一消息，确认不滞留旧 `Provider test failed` 状态且 SSE 流正常关闭。
