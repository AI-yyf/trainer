## 3. 分项目子计划

### 3.1 对话视图增强

**目标**: 提升空对话体验，增强动作可见性

**实现**:
1. 空对话起手建议 (CoachWelcomeSuggestions)
   - 基于当前工作区上下文推荐起手动作
   - "开始学习这个项目"、"上传资料"、"制定计划"
   
2. 轻量动作状态 (CoachActionIndicator)
   - "正在查资料..." | "正在对齐计划..." | "正在编排训练..."
   - 非阻塞式，显示在消息气泡内

3. 结果回流提示
   - 消息末尾显示 "📌 已沉淀为卡片 / 已添加到计划"

**文件变更**:
- `CoachConversationView.tsx` - 空状态优化
- `CoachWelcomeSuggestions.tsx` (新) - 起手建议组件
- `CoachActionIndicator.tsx` (新) - 动作状态组件

### 3.2 训练视图增强

**目标**: 提升训练卡片视觉吸引力和激励机制

**实现**:
1. 闪记卡连胜动画
   - 连续答对显示 "🔥 连击 X" 动画
   - 配合卡片边框颜色渐变

2. 实战卡进度追踪
   - 顶部进度条显示 "已完成 X/Y"
   - 侧边缩略图显示当前任务位置

3. 复盘卡智能建议
   - 基于错误类型推荐下一张卡
   - 显示 "根据这次练习，推荐: XXX"

**文件变更**:
- `CoachFlashView.tsx` - 连击动画
- `CoachPracticeView.tsx` - 进度追踪
- `TrainingCardRenderer.tsx` - 增强渲染

### 3.3 资料视图增强

**目标**: 完善知识转化链可视化

**实现**:
1. 资料条目转化状态
   - 显示 "可转化为: 闪记卡 | 实战卡 | 计划证据"
   - 一键转化按钮

2. 来源追踪
   - 显示资料来源 (上传/网页抓取/项目索引)
   - 处理日志折叠展示

3. 知识原子卡片
   - 原子化后的知识条目独立展示
   - 关联的训练卡片链接

**文件变更**:
- `CoachResourcesView.tsx` - 转化链
- `ResourceTransformPanel.tsx` (新) - 转化面板

### 3.4 计划视图增强

**目标**: 完善证据可视化和状态展示

**实现**:
1. 证据来源标记
   - 训练完成 → 证据 → 计划采纳
   - 可视化证据链路

2. 阻断状态清晰化
   - 阻断原因 + 替代动作建议
   - 非阻断时正常推进

3. 进度概览
   - 阶段进度条
   - 当前阶段高亮

**文件变更**:
- `CoachPlanView.tsx` - 证据可视化
- `PlanEvidenceChain.tsx` (新) - 证据链组件

### 3.5 设置视图优化

**目标**: 简化首次配置流程

**实现**:
1. 引导式设置进度
   - 4 步完成基本配置
   - 进度可视化

2. Provider 模板快捷选择
   - 卡片式模板列表
   - 一键填充配置

3. 连接状态实时反馈
   - 测试按钮 → 实时状态

**文件变更**:
- `CoachSettingsView.tsx` - 引导流程
- `ProviderTemplateCards.tsx` (新) - 模板卡片

### 3.6 Skill 逻辑扩展

**目标**: 覆盖更多使用场景

**实现**:

## 4. 设计细节规范

### 4.1 空状态设计

| 视图 | 当前状态 | 目标状态 |
|------|----------|----------|
| 对话 | 空白输入框 | "有什么想学的？" + 快捷建议 |
| 计划 | "暂无计划" | "先定个目标" + 创建按钮 |

| 训练 | 无训练 | "开始学习" + 能力测评 |

### 4.2 状态诚实性

| 状态 | 显示方式 |
|------|----------|
| 工作中 | 消息内加载指示器 |
| 受阻 | 红色警告 + 替代建议 |
| 完成 | 绿色标记 + 回流提示 |
| 待采纳 | 黄色标记 + 操作按钮 |

### 4.3 交互一致性

- 所有按钮悬停效果一致
- 键盘导航完整
- 主题切换无闪烁
- 窄宽度自适应

## 7. 风险与缓解

| 风险 | 影响 | 缓解措施 |
|------|------|----------|
| 多语言翻译不一致 | 用户体验 | 人工审核 + 社区贡献 |
| 性能退化 | 使用流畅度 | 懒加载 + 虚拟滚动 |
| 状态同步延迟 | 教练响应 | 乐观更新 + 回滚 |
| 自进化逻辑复杂 | 开发成本 | MVP 原型 + 迭代 |

---

## 8. 成功标准

1. **用户角度**: 打开 Trainer，3 步内开始第一次学习
2. **教练角度**: 能追踪用户从资料到掌握的完整路径
3. **架构角度**: 五个视图各司其职，状态诚实
4. **国际化角度**: 8 种语言无缝切换
5. **性能角度**: 首屏 < 1s，操作响应 < 100ms
