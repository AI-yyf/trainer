## 背景与目标

Trainer 需要成为"跨项目统一的最强代码教练"，每个视图（会话、训练、计划、资料、设置）都必须满足：

1. **低理解成本**：新用户一眼看懂这是什么、能做什么
2. **参考成熟产品**：借鉴 Claude Code、Notion、Linear 等的设计思路
3. **做减法**：去除冗余，保留核心

## 跨视图统一原则

### 视觉层级
- 标题: 14px / 600 weight
- 正文: 12px / 400 weight
- 标签: 10px / 500 weight
- 间距基准: 4px 网格

### 状态设计
- 空状态: 引导 + 图标 + 操作
- 加载状态: 骨架屏或进度指示
- 错误状态: 清晰说明 + 解决建议

### 动画原则
- 入场: 从下向上滑入，150-200ms
- 反馈: 点击反馈 50ms
- 过渡: 视图切换 200ms
- 不要过度动画，保持专业感
