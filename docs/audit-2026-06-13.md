- 代码/文本: Shiki 高亮 (`ShikiCodeBlock.tsx`)

- DOCX: docx-preview + Mammoth.js (`DocxPreview.tsx`)
- CSV/TSV: **新增强** - TanStack Table (`CSVPreview.tsx`) ✅
- 音频: wavesurfer.js (`AudioPreview.tsx`)
- 图片/视频: 原生 `<img>` / `<video>` + native open fallback

**已实现 (Tier B - 转换预览)**:
- `MarkItDown` 集成 (server/app/resources/preview.py)
- Archive listing for ZIP/TAR
- Notebook JSON structured preview

**已实现 (Tier C - 元数据兜底)**:

- Binary file hash + mime detection

**引用的开源项目**:

**缺失项**:
