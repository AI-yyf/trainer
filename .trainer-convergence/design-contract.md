# Design Contract (locked)

Goal: 图多字少、一眼看懂、操作简单、反馈自然、视觉精美、功能完整。

- Token-driven visuals only; no hardcoded colors; five-step icon optical scale (12/14/16/18/20) is frozen.
- One primary next action per initial viewport; secondary options are progressive disclosure.
- Internal terms (sidecar, generation, registry) never surface to users.
- Errors render next to their action; success claims must be backed by real results.
- Key acceptance windows: 340×450, 340×600, 400×700, 760×800, 1200×800, 200% font, zh-CN + en-US.
- Every UI change needs visual + interaction + full-journey review, not only "no CSS overflow".
